UMG - EXAMEN PRACTICO DEVOPS

1. Descomprima el proyecto en la ubicación indicada.
2. Ejecute INICIAR_EXAMEN.bat.
3. Espere npm install y npm test.
4. VS Code se abrirá automáticamente cuando esté disponible.
5. Realice únicamente las actividades solicitadas.
6. NO modifique ni elimine .exam o scripts.
7. Al terminar ejecute FINALIZAR_EXAMEN.bat.
8. Muestre RESUMEN_EXAMEN.txt al docente.

El equipo registra evidencia técnica básica del examen (procesos configurados,
extensiones, heartbeat y evidencia Git/npm). No registra teclas, contraseñas,
portapapeles ni contenido de pantalla.
